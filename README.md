# RouteGuard

Выборочный WAN kill switch для OpenWrt. Блокирует прямой выход к известным IP выбранных сервисов через указанные WAN-устройства.

## Как работает

- **LuCI и UCI.** В LuCI вы настраиваете профили, WAN и исключения. Настройки сохраняются в UCI.
- **Движок Go.** Собирает IP из ручных записей, доменов и удалённых списков, применяет правила и сохраняет снимок для восстановления и отката.
- **nftables и cron.** Ядро фильтрует трафик, а системный cron обновляет адреса по расписанию, если оно задано.

## Установка

Пакеты рассчитаны на официальный OpenWrt 25.12. Установщик автоматически выбирает архитектуру APK.

Выполните на роутере от root:

```sh
sh <(wget -O - https://raw.githubusercontent.com/ZeeeUs/RouteGuard/refs/heads/main/install.sh)
```

Скрипт скачивает готовые APK из GitHub Releases, сверяет контрольные суммы и устанавливает пакеты.

## Совместимость

| Архитектура пакета   | Устройства и платформы                         | Проверка на реальном устройстве |
| -------------------- | ---------------------------------------------- | ------------------------------- |
| `aarch64_cortex-a53` | MediaTek Filogic (`mediatek/filogic`)          | ✅                              |
| `aarch64_generic`    | NanoPi R2S / R4S / R5S / R6S, `rockchip/armv8` | ❌                              |
| `aarch64_cortex-a72` | Raspberry Pi 4 / CM4, `bcm27xx/bcm2711`        | ❌                              |
| `aarch64_cortex-a76` | Raspberry Pi 5, `bcm27xx/bcm2712`              | ❌                              |
| `x86_64`             | Мини-ПК и виртуальные машины, `x86/64`         | ❌                              |

Все пять архитектур включены в матрицу релизной сборки. Проверка на MediaTek MT7981B с OpenWrt 25.12.5 подтвердила установку, блокировку в цепочках OUTPUT и FORWARD и работу защиты после перезагрузки и `fw4 reload`. Остальные модели той же архитектуры требуют проверки. FriendlyWrt, ImmortalWrt и заводские прошивки производителей пока не проверены.

## Первый запуск

1. Отключите программный и аппаратный **flow offloading** в настройках Firewall.
2. Откройте **Службы → RouteGuard**. Укажите устройства WAN и выберите режим IPv6.
3. Добавьте и включите профиль с IP, доменами или ссылкой на список. Для доменов и списков укажите DNS-резолвер.
4. Включите RouteGuard и нажмите **Save & Apply**. Состояние правил и счётчики появятся на вкладке **Status**.

RouteGuard поставляется с пустой конфигурацией. Фильтрация начинается после применения настроек. Адреса вне собранного набора проходят, а в режиме IPv6 Off фильтруется только IPv4.
