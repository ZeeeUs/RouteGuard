# RouteGuard

Выборочный WAN kill switch для OpenWrt. Блокирует прямой выход к известным IP выбранных сервисов через указанные WAN-устройства.

## Как работает

- **LuCI и UCI.** В LuCI вы настраиваете профили, WAN и исключения. Настройки сохраняются в UCI.
- **Движок Go.** Собирает IP из ручных записей, доменов и удалённых списков, применяет правила и сохраняет снимок для восстановления и отката.
- **nftables и cron.** Ядро фильтрует трафик, а системный cron обновляет адреса по расписанию, если оно задано.

## Установка

Готовые пакеты рассчитаны на OpenWrt 25.12, `mediatek/filogic`, `aarch64_cortex-a53`.

Выполните на роутере от root:

```sh
installer=$(wget -O - https://github.com/ZeeeUs/RouteGuard/releases/latest/download/install.sh) && printf '%s\n' "$installer" | sh
```

## Первый запуск

1. Отключите программный и аппаратный **flow offloading** в настройках Firewall.
2. Откройте **Службы → RouteGuard**. Укажите устройства WAN и выберите режим IPv6.
3. Добавьте и включите профиль с IP, доменами или ссылкой на список. Для доменов и списков укажите DNS-резолвер.
4. Включите RouteGuard и нажмите **Save & Apply**. Состояние правил и счётчики появятся на той же странице.

RouteGuard поставляется с пустой конфигурацией. Фильтрация начинается после применения настроек. Адреса вне собранного набора проходят, а в режиме IPv6 Off фильтруется только IPv4.
